NOTA METODOLÓGICA

Os resultados são apresentados conforme os campos disponibilizados pela instituição de origem. Cores são recursos de identificação visual de siglas partidárias, não representam avaliação ou classificação. Na Câmara, a busca consulta a API oficial com limite de 100 registros por requisição. No Senado, a lista de parlamentares em exercício é carregada uma vez e filtrada localmente. Fontes: APIs oficiais das duas Casas.
